🧠 Deep Learning Projects

This repository contains multiple Deep Learning and AI-based projects developed using Python, TensorFlow, and PyTorch.
Each project focuses on solving real-world problems in areas like Natural Language Processing (NLP) and Computer Vision.

📂 Projects Included

🗣️ Sentiment Analysis – Classifies text into positive, negative, or neutral sentiments.

💬 Short Text Emotion Detection – Detects emotions like happiness, anger, or sadness from short texts.

🖼️ Object Detection – Identifies and locates multiple objects in images or videos using YOLO.

💳 Fraud Detection – Predicts fraudulent transactions using anomaly detection and neural networks.

⚙️ Tech Stack

Languages: Python

Frameworks: TensorFlow, Keras, PyTorch

Libraries: NumPy, Pandas, OpenCV, Scikit-learn, Matplotlib

Tools: Jupyter Notebook, Google Colab

🎯 Goal

To build intelligent, data-driven solutions through Deep Learning that can understand, predict, and automate real-world scenarios.
